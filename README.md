<h1 align="center">Better Sonar</h1>

<p align="center">An unofficial Windows app for switching between headphones and speakers in SteelSeries GG.</p>

<p align="center">
  <a href="https://github.com/wooseongDev/better-sonar/releases/latest"><strong>Download for Windows</strong></a>
</p>

<p align="center">Requires Sonar for Streamers to be enabled in SteelSeries GG.</p>

## Features

- **Switch between headphones and speakers.** See the current Personal Mix output and switch between your saved devices using the app, the system tray, or a custom global shortcut.
- **Choose devices from the tray.** Select outputs for Personal Mix and Stream Mix and choose a microphone input.
- **Control volume with media keys.** Use Windows media keys to mute, unmute, or adjust the Personal Mix volume.
- **Keep shortcuts active in the background.** Closing the window hides the app to the tray. You can also start the app automatically when you sign in to Windows.
- **Reconnect and update.** Better Sonar automatically tries to reconnect when it loses its connection to Sonar. You can check for and install updates in the app.
